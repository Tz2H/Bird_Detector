# 鸟类检测系统 - 首次运行指南

本指南适用于当前 uv 工作区版本（macOS 优先）。

## 快速入门（源码运行）

1. 在项目根目录安装依赖：
   ```bash
   uv sync
   ```
2. 启动程序（推荐）：
   ```bash
   uv run bird-detector
   ```
   或使用入口文件：
   ```bash
   uv run python src/main.py
   ```

## 快速入门（打包后运行）

1. 在项目根目录执行打包：
   ```bash
   uv run python build_nuitka.py
   ```
2. macOS 默认产物：
   - `dist/BirdDetectorApp.app`
3. 首次在 macOS 打开 `.app` 可能提示来源未验证：
   - 可在系统设置中手动允许后重试
   - 或在终端移除隔离属性（仅对你信任的构建产物执行）：
     ```bash
     xattr -dr com.apple.quarantine dist/BirdDetectorApp.app
     ```

## 使用说明

### 界面组成（详细）

#### 1. 菜单栏（窗口顶部）

- **文件**
   - **打开视频**（快捷键 `Ctrl+O`）：选择本地视频文件作为输入源。
   - **保存数据**（快捷键 `Ctrl+S`）：将当前检测到的数据导出为 CSV。
   - **退出**（快捷键 `Ctrl+Q`）：关闭程序。
- **视图**
   - **全屏**（快捷键 `F11`）：在全屏和普通窗口间切换。
- **帮助**
   - **关于**：显示版本与版权信息。

#### 2. 顶部操作区

- **设置**按钮：打开设置总入口，包含两个子功能。
   - **模型设置**：选择 `.pt` 模型文件，并勾选“需要参与识别”的类别。
   - **密度图设置**：勾选“需要显示在右侧曲线图”的类别。
- **保存数据为 CSV**按钮：与菜单栏“文件 -> 保存数据”作用一致。

#### 3. 左侧主检测区

- **视频控制条**
   - **视频源**下拉框：显示“摄像头/视频文件”选项（当前版本主要用于界面展示与后续扩展）。
   - **分辨率**下拉框：显示常用分辨率选项（当前版本主要用于界面展示与后续扩展）。
- **实时画面区**
   - 显示摄像头或视频画面。
   - 检测开启后会绘制识别框与类别标签。
- **状态信息条**
   - **识别到的鸟类数量**：显示当前帧统计值。
   - **FPS**：显示平滑后的帧率估计。

#### 4. 右侧分析与控制区

- **数量密度分布图**
   - 展示已勾选密度类别的时间序列曲线。
   - 无数据时会显示“暂无数据”。
- **开始检测 / 停止检测**按钮
   - 点击“开始检测”进入推理状态。
   - 点击“停止检测”后停止推理，但仍会继续刷新画面预览。
- **进度条**
   - 当前版本预留，默认隐藏。

#### 5. 状态栏与系统托盘

- **状态栏（窗口底部）**：显示“系统就绪、已打开视频、加载模型成功、错误提示”等即时消息。
- **系统托盘图标**：右键可执行“显示/退出”。

### 关键交互流程

1. 启动后点击 **设置** -> **模型设置**，确认模型与识别类别。
2. 如需调整曲线展示类别，点击 **设置** -> **密度图设置**。
3. 选择输入源：
    - 打开本地视频：使用“文件 -> 打开视频”。
    - 使用摄像头：点击“开始检测”后会弹出“选择摄像头”对话框。
4. 检测过程中观察：
    - 左侧画面与实时计数/FPS。
    - 右侧密度曲线（按已选密度类别更新）。
5. 需要导出时，使用顶部 **保存数据为 CSV** 或菜单“文件 -> 保存数据”。

### 结果分析

- 检测结果实时显示在主界面。
- 统计曲线在右侧面板持续刷新。
- 检测记录与趋势图会写入 `results/` 目录。

## 常见问题

### 启动失败

- 确认已在项目根目录执行 `uv sync`
- 确认使用的是当前项目环境启动：`uv run bird-detector`
- 若为打包版本，确认 `dist/BirdDetectorApp.app` 已生成

### 启动后无法检测

- 检查模型文件是否存在（应位于 `src/resources/models/`）
- 确保摄像头已正确连接并被系统识别
- 检查 `config.txt` 中模型路径是否可用

### 检测速度慢

- 在设置中降低处理分辨率
- 使用较小模型或减少识别类别数量
- 若设备支持，确保已正确安装并启用 CUDA（仅 NVIDIA 环境）

## 相关目录

- `src/resources/`：模型和静态资源
- `results/`：检测结果与导出数据
- `config.txt`：默认配置
